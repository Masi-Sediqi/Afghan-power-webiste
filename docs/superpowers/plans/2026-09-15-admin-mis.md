# Admin MIS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build secure first-admin setup/login and a static MIS admin shell at `/admin`.

**Architecture:** Extend the existing Node/TypeScript API with an `admins` PostgreSQL table and separate admin session cookie. Add an isolated React `AdminApp` selected by pathname so the public site remains unchanged.

**Tech Stack:** React 18, TypeScript, Vite, Node HTTP server, PostgreSQL, lucide-react.

**Spec:** `docs/superpowers/specs/2026-09-15-admin-mis-design.md`

## Global Constraints
- No default admin credentials.
- Setup is permitted only when no admin exists.
- Separate customer/admin sessions.
- Sidebar sections are Dashboard, Products, Services, News, About, Contact, Messages & Requests.
- Section content is static in phase one.
